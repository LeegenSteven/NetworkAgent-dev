# 5G Network Agent Demo Script

## Overview

This demo showcases how AI agents can accelerate a telco's journey to a more autonomous network. The demo features multiple specialized agents that can chat with users or execute background tasks triggered by external events.

### Key Agents
- **Network Engineering Agent**: Simplifies network design and build processes, automating tasks and reducing errors
- **Operations Agent**: Provides insights about existing network infrastructure and status

## Demo Setup

The demo begins with a partially configured 5G network where core network components are installed but additional services need to be deployed.

### Initial Setup Steps
1. Install core components using the provided installation script
2. Access the Git server using the link provided after installation completes
3. Login with your configured username and password from environment variables
4. Navigate to the **network** repository
5. Select the **core** branch to view the Kubernetes Custom Resources (CRs)
6. Create a pull request to merge the **core** branch into master
7. Monitor the automation logs in the demo dashboard as core network functions are instantiated via GKE

## Demo Script

### 1. Introduction and UI Tour

**Demo Points:**
- Explain the autonomous network vision and AI agent capabilities
- Highlight that the UI was 100% generated by AI agents without manual coding
- Show the end-to-end virtual 5G network running on Google Cloud

**UI Walkthrough:**
1. **Network Topology View**
   - Display the partially deployed 5G network
   - Show control plane, user plane, and fake internet connections
   - Demonstrate Google Cloud virtual network connectivity

2. **Node Details** *(Click on a network node)*
   - Show current configuration and status
   - Explain agent access to Google Cloud automation and monitoring tools

3. **Logs Panel** *(Open Logs)*
   - Display automation tool and network function logs
   - Explain how the incident agent uses logs for root cause analysis

4. **Metrics View** *(Click on Metrics)*
   - Show real-time network performance metrics from Google Cloud
   - Explain how agents correlate performance data for analysis

5. **Chat Interface** *(Click on Chat)*
   - Test initial agent availability:
     - "What can you do for me?"
     - "What agents are there?"
   - Note: No agents are initially configured

### 2. GitOps Demonstration *(Extended Version)*

**Objective:** Show GitOps approach for network intent changes

**Steps:**
1. Open Gitea and login
2. Navigate to the **core** repository
3. Show Custom Resources responsible for current UI display
4. Navigate to the **cellsite2** repository
5. Create pull request to merge **location** branch into master
6. Observe new VPC creation (cellsite2) appearing in UI
7. Monitor real-time logs during deployment

### 3. Operations Agent Setup

**Objective:** Add network operations capabilities

**Steps:**
1. Add Operations Agent via Settings screen
2. Open agent chat window on Dashboard UI left panel

**Demo Queries:**
- "What network services can I deploy?"
- "More details on UERanSIM"
- "Any rules I should know about?"
- "What network services are already deployed?"
- "What is the status of the control plane network service?"
- "What locations are there?"

**Key Points:**
- Agent learns from automation platform and technical documentation
- No hardcoded logic - dynamic reasoning based on updated information
- Real-time access to network status and configuration

### 4. Network Engineer Agent Demo

**Objective:** Demonstrate network design and deployment automation

**Setup:**
1. Clear chat history
2. Add Engineer Agent via Settings screen

**Demo Scenarios:**

**Scenario 1: Basic Network Location**
- Query: "Create a plan to deploy a new network location called cellsite1 with CIDR 10.0.40.0/24"

**Scenario 2: Complex Network Deployment**
- Query: "Can you create a plan to add a radio simulator to cellsite1 and a working 5G network?"
- Observe automatic inclusion of point-to-point VPN service based on network design documentation

**Scenario 3: Plan Modifications**
- "Can you change the name of the PTP service to brian-ptp?"
- "Can you reorder the tasks so the PTP service is before/after the UERanSIM task?"
- Approve execution with "Yes"

**Monitoring:**
- **Logs Panel**: Watch real-time network function logs stored in Google Cloud
- **Metrics Screen**: Observe live performance metrics collection
- **Result**: Operational 5G mobile network ready for testing

### 5. Test Agent Demonstration

**Objective:** Validate network functionality

**Steps:**
1. Add Test Agent via Settings screen
2. Request test execution: "Run a test from a UERanSIM instance to a DNN instance"
3. Monitor live metrics via Metrics screen (top-right dashboard button)
